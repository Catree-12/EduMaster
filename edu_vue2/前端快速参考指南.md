# 前端开发快速参考指南

## 🎯 核心概念澄清

### 权限模型
- **不是全局角色系统**（没有固定的"老师"和"学生"角色）
- **是基于课程的权限系统**：
  - 用户创建课程 → 该课程内为**教师/创建者**
  - 用户选修他人课程 → 该课程内为**学生**
  - 管理员身份全局

### 课程体系架构 (新增重要概念)
```
课程 (Course)
  └─ 班期 (Term/Batch) - 同一课程的不同时间段版本
      └─ 班级 (Class) - 该班期内的学生分组
          ├─ 学生列表
          ├─ 考试发布到班级
          ├─ 作业发布到班级
          └─ 讨论区
```

**关键理解：** 你卖课的业务模式
- 一个课程可开设多个班期（春季班、夏季班等，或课程内容更新后重新开班）
- 每个班期可包含多个班级（满班时新建班级）
- 题库可随班期迭代
- 通过班级来管理学生和发布考试、作业

### 电子证书系统 (新增)
- 学生参加考试 → 通过考试（成绩 >= 及格线）→ 自动颁发电子证书
- 用途：作为"结业考核"凭证
- 功能：证书展示、下载、分享

### 课程发布流程
```
用户创建课程（草稿）
    ↓
用户发布课程申请（待审核）
    ↓
管理员审核
    ├─ 通过 → 课程发布（显示在课程大厅）
    └─ 拒绝 → 回到草稿（显示拒绝原因）
```

### 菜单导航结构
- **首页** - 所有用户看到
- **课程中心** - 显示已发布的课程
- **我的课程** - 两个标签页
  - 我教的课（我创建的）+ **创建课程按钮**
  - 我学的课（我选修的）
- **我的证书** ⭐ 新增 - 显示已获得的电子证书
- **个人中心** - 用户信息管理
- **社区** - 交流讨论
- **[管理员]** - 仅管理员看到（审核、用户管理等）

## 💡 实现技巧

### 课程权限判断
```javascript
// 检查用户是否为某课程创建者
const isCourseCreator = (userId, courseId) => {
  return userCourses.find(c => c.id === courseId && c.creator === userId)
}

// 在编辑页面的路由守卫中
beforeEnter: (to, from, next) => {
  const courseId = to.params.id
  const userId = store.state.user.id
  if (isCourseCreator(userId, courseId)) {
    next()
  } else {
    next('/403')
  }
}
```

### 班级学生管理代码示例
```javascript
// 添加学生到班级
addStudentToClass(courseId, termId, classId, studentId) {
  const classObj = this.getClass(courseId, termId, classId)
  if (classObj.students.length < classObj.capacity) {
    classObj.students.push(studentId)
    return true
  }
  return false  // 班级已满
}

// 批量导入学生
importStudents(courseId, termId, classId, studentList) {
  const classObj = this.getClass(courseId, termId, classId)
  const available = classObj.capacity - classObj.students.length
  if (studentList.length <= available) {
    classObj.students.push(...studentList)
    return { success: true, count: studentList.length }
  }
  return { success: false, message: '班级容量不足' }
}
```

## ⭐ 关键业务流程总结

### 1. 课程创建→发布→审核→上架
```
教师创建课程 (DRAFT)
    ↓
教师编辑课程内容
    ↓
教师点击"发布" (PENDING)
    ↓
管理员审核
    ├─ 通过 → PUBLISHED (在课程大厅显示)
    └─ 拒绝 → 回到 DRAFT (显示拒绝原因)
```

### 2. 班期→班级→学生
```
教师为课程创建班期 (如：2024春季班)
    ↓
教师在班期内创建班级 (如：一班、二班)
    ↓
学生选课：选择班期 → 选择班级
    ↓
学生加入班级
    ↓
教师可向班级发布考试、作业
```

### 3. 考试→通过→证书
```
学生参加考试
    ↓
自动批改（客观题）/ 手动批改（主观题）
    ↓
成绩 >= 及格线
    ↓
自动生成电子证书
    ↓
学生在"我的证书"页面查看、下载、分享
```
