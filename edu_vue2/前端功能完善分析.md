## 📚 第二部分：课程管理模块

### 系统架构说明
- **课程 (Course)** - 基础课程信息（可多次迭代）
- **班期/期次 (Term/Batch)** - 同一课程的不同时间段
- **班级 (Class)** - 某个班期内的学生分组
- **考试 (Exam)** - 发布到班级的考试（题目可迭代）
- **电子证书 (Certificate)** - 考试通过后颁发

### ✅ 已实现
- [x] 课程中心展示 (`CourseCenter.vue`)
  - 包含搜索、分类筛选、分页
  - 展示已发布的课程（已审核通过）
- [x] 课程详情页 (不完善)
- [x] 我的课程列表 (`MyCourses.vue` - 占位符)
- [x] 我的课程详情 (`MyCourseDetail.vue` - 功能完整)
- [x] 教师课程管理 (`TeacherCourseDetail.vue`)

#### 班期与班级管理 ★★★★ (新增 - 关键功能)
- [ ] **班期（期次）管理** - 缺失
  - 概念：同一课程可多次开设，每次称为一个班期
  - 目的：支持课程迭代、题库更新、学生分批
  - 功能：
    - 为课程创建班期（指定开课时间）
    - 编辑班期信息
    - 查看班期内容版本
    - 删除班期（未开课的情况）
  - 路由建议：
    - `/teacher/course/:courseId/terms` - 班期列表
    - `/teacher/course/:courseId/terms/:termId/edit` - 班期编辑

- [ ] **班级管理** - 缺失
  - 概念：班期内的学生分组
  - 目的：便于向特定学生批量发布考试、作业
  - 功能：
    - 在班期内创建班级
    - 班级命名（如：一班、二班）
    - 添加学生到班级（单个/批量导入）
    - 编辑班级信息
    - 查看班级学生列表
    - 删除班级
  - 数据模型：
    ```
    Class {
      id: String,
      courseId: String,
      termId: String,
      name: String,           // 班级名称
      description: String,
      capacity: Number,       // 班级容量
      students: Array<String>,// 学生ID列表
      createdAt: Date,
      status: String          // active/archived
    }
    ```
  - 路由建议：
    - `/teacher/course/:courseId/terms/:termId/classes` - 班级列表
    - `/teacher/course/:courseId/terms/:termId/classes/:classId/students` - 班级学生管理
