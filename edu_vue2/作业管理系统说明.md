# 作业管理系统实现说明

## 新增页面

### 1. 作业库页面 (`HomeworkLibrary.vue`)
- 路径：`/teacher/homework/library`
- 功能：
  - 显示教师创建的所有作业
  - 搜索作业
  - 查看作业详情
  - 使用作业（可在课程中发布）
  - 删除作业
  - 创建新作业按钮

### 2. 作业详情页 (`HomeworkDetail.vue`)
- 路径：`/teacher/homework/:id/detail`
- 功能：
  - 显示作业的完整题目内容
  - 显示所有题型（单选、多选、填空、判断、简答）
  - 显示正确答案（标记为绿色）
  - 右上角"重新编辑"按钮

### 3. 作业编辑页 (`HomeworkEdit.vue`)
- 路径：`/teacher/homework/:id/edit`
- 功能：
  - 编辑作业基本信息（名称、描述）
  - 编辑每道题目的内容
  - 编辑每道题的分值
  - 修改正确答案
  - **限制**：不能添加或删除题目

### 4. 新建作业页 (`HomeworkCreate.vue`)
- 路径：`/teacher/homework/create`
- 功能：
  - 按照附件图片的结构设计
  - 左侧设置面板：
    - 作业类型选择（题目型/答题卡）
    - 评分机制选择（百分制/自定义）
    - 题型设置（按题型归类/不归类）
  - 右侧题目编辑区：
    - 工具栏：单选题、多选题、填空题、判断题、简答题按钮
    - 智能导入、选题、更多按钮
    - 题目列表（支持拖拽排序）
    - 每道题可编辑、复制、删除
  - 题目编辑对话框
  - 动态计算总分

## 功能流程

### 创建作业流程
1. 教师点击"新建作业"按钮 → 进入 `/teacher/homework/create`
2. 选择作业类型和评分机制
3. 点击题型按钮添加题目
4. 填写题目内容、选项、答案
5. 拖拽调整题目顺序
6. 点击"保存"或"保存并发布"

### 查看作业流程
1. 教师点击"作业库"按钮 → 进入 `/teacher/homework/library`
2. 点击某个作业 → 进入 `/teacher/homework/:id/detail`
3. 查看完整题目和答案

### 编辑作业流程
1. 在作业详情页点击"重新编辑" → 进入 `/teacher/homework/:id/edit`
2. 编辑题目内容、选项、答案、分值
3. **注意**：不能添加或删除题目
4. 点击"保存"

### 在课程中使用作业
1. 在课程详情页的"作业"模块
2. 点击作业列表中的作业项 → 进入作业详情页
3. 或点击"作业库" → 选择作业 → 在课程中发布

## 依赖安装

需要安装 vuedraggable 用于题目拖拽排序功能：

```bash
npm install vuedraggable
```

或

```bash
yarn add vuedraggable
```

## 数据结构

### 作业对象
```javascript
{
  id: Number,
  name: String,          // 作业名称
  description: String,   // 作业描述
  type: String,          // 'question' | 'file'
  gradingType: String,   // 'auto' | 'custom'
  questionTypeMode: String, // 'by-type' | 'no-type'
  totalPoints: Number,
  questionCount: Number,
  createdAt: String,
  questions: [
    {
      id: Number,
      type: String,      // 'single' | 'multiple' | 'fill' | 'judge' | 'essay'
      title: String,     // 题目内容
      options: Array,    // 选项（单选/多选题）
      answer: Any,       // 答案（单选：Number, 多选：Array, 填空/简答：String, 判断：Boolean）
      points: Number     // 分值
    }
  ]
}
```

## 注意事项

1. **拖拽功能**：需要先安装 `vuedraggable` 依赖
2. **题目编辑限制**：编辑页面不允许添加或删除题目，只能修改现有题目内容
3. **分值计算**：
   - 百分制模式：总分固定100分，平均分配到每道题
   - 自定义模式：可以为每道题设置不同分值
4. **答案验证**：在保存前需要验证是否设置了正确答案
