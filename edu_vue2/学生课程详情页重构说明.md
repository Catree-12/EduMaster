## 📋 重构概览

已完成对 `StudentCourseDetail.vue` 的全面重构，实现了统一的UI设计和增强的用户体验。

## ✨ 主要改进

### 1. 章节模块 - 双栏布局
- **左侧内容播放器**：
  - 视频播放占位区（黑色背景 + 播放按钮）
  - 课程信息展示（课程名称 + 时长）
  - 最小高度 400px，确保观看体验

- **右侧章节目录**：
  - 顶部搜索框，支持实时搜索章节和课程
  - 可展开/收起的章节列表
  - 展开图标动画过渡效果
  - 课程点击选中高亮显示
  - 显示课程类型图标（🎥视频/📄文档）
  - 显示课程时长

### 2. 作业模块 - 统一卡片设计
- **顶部课程标题栏**：渐变紫色背景
- **筛选标签栏**：
  - 全部
  - 已完成（已提交/已批改）
  - 未完成（待提交）
- **任务列表**：
  - 灰色"作业"类型徽章
  - 任务标题和元信息
  - 状态标签（颜色区分）
  - 悬停效果：边框高亮 + 阴影 + 上移

### 3. 考试模块 - 与作业统一设计
- **相同的UI结构**：
  - 课程标题栏
  - 筛选标签栏
  - 任务列表
- **考试特有元素**：
  - 灰色"考试"类型徽章
  - 显示时长、题目数量、得分
  - 智能点击处理（未开始/进行中/已完成）

## 📊 数据结构

### 新增状态
```javascript
homeworkFilter: 'all',      // 作业筛选：all/completed/incomplete
examFilter: 'all',           // 考试筛选：all/completed/incomplete
chapterSearch: '',           // 章节搜索关键词
currentLesson: null,         // 当前选中课程
expandedSections: []         // 展开的章节ID列表
```

### 计算属性
- `filteredHomeworks`：根据筛选条件返回作业列表
- `filteredExams`：根据筛选条件返回考试列表
- `filteredSections`：根据搜索关键词返回章节列表

### 新增方法
- `toggleSection(sectionId)`：切换章节展开/收起
- `selectLesson(lesson)`：选择要播放的课程
- `handleExamClick(exam)`：智能处理考试点击事件
