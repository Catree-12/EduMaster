## 🔄 关键页面的状态转换

### 我的课程（MyCourses.vue）

```
MyCourses.vue
├── 标签页 1: 我教的课
│   ├── 创建课程按钮 → CourseCreate.vue
│   ├── 课程卡片
│   │   ├── 查看 → CourseDetail.vue
│   │   ├── 编辑 → CourseEdit.vue
│   │   ├── 发布 → 发送审核请求
│   │   ├── 下架 → 更新状态
│   │   └── 删除 → 删除课程
│   │
│   └── 编辑后的操作
│       ├── 班期管理 → TermManagement.vue
│       └── 班级管理 → ClassManagement.vue
│
└── 标签页 2: 我学的课
    ├── 课程卡片
    │   ├── 继续学习 → CourseDetail.vue
    │   └── 退课 → 取消选课
    │
    └── 空状态 → 去选课 → CourseCenter.vue
```

### 课程选课流程

```
CourseCenter.vue (浏览已发布课程)
    ↓
选择课程
    ↓
CourseDetail.vue (课程详情)
    ↓
点击"选课"
    ↓
TermSelector.vue (选择班期)
    ↓
ClassSelector.vue (选择班级)
    ↓
加入班级
    ↓
开始学习 → 进入 CourseDetail.vue
```

### 证书获取流程

```
学生参加考试
    ↓
ExamAnswer.vue (答题)
    ↓
提交答卷
    ↓
ExamResult.vue (查看成绩)
    ↓
成绩通过
    ↓
自动生成证书
    ↓
用户进入 MyCertificates.vue
    ↓
查看、下载、分享证书
    └─ CertificateDetail.vue (查看详情)
    └─ CertificateShare.vue (分享证书)
```

### 3. API 接口整理

**课程相关:**
- `GET /courses` - 获取所有已发布课程
- `POST /courses` - 创建课程
- `GET /courses/:id` - 获取课程详情
- `PUT /courses/:id` - 编辑课程
- `PUT /courses/:id/publish` - 发布课程
- `PUT /courses/:id/archive` - 下架课程
- `DELETE /courses/:id` - 删除课程
- `GET /user/teaching-courses` - 获取我教的课程
- `GET /user/learning-courses` - 获取我学的课程
- `POST /user/courses/:id/drop` - 退课

**班期班级相关:**
- `GET /courses/:courseId/terms` - 获取班期列表
- `POST /courses/:courseId/terms` - 创建班期
- `GET /courses/:courseId/terms/:termId/classes` - 获取班级列表
- `POST /courses/:courseId/terms/:termId/classes` - 创建班级

**证书相关:**
- `GET /user/certificates` - 获取我的证书列表
- `GET /user/certificates/stats` - 获取证书统计
- `GET /certificate/:id` - 获取证书详情
- `GET /certificate/:id/download` - 下载证书 PDF
- `POST /certificate/:id/generate-share-link` - 生成分享链接
- `GET /certificate/share/:shareCode` - 获取公开证书信息

**管理员相关:**
- `GET /admin/courses/pending` - 获取待审核课程列表
- `PUT /admin/courses/:id/approve` - 审核通过课程
- `PUT /admin/courses/:id/reject` - 拒绝课程
