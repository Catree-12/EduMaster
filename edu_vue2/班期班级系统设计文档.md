# 班期班级系统设计文档

## 📚 核心概念

### 为什么需要班期（Term/Batch）？

你的业务模式是**卖课**，而不是**学校教学**。关键特点：

1. **课程迭代** - 同一课程需要多次开设
   - 春季班、夏季班、秋季班...
   - 课程内容更新后重新开班
   - 考试题库可能不同

2. **学生分批** - 高热度课程需要分班
   - 控制班级规模（如：每班50人）
   - 满班后新建班级
   - 便于管理和批量操作

3. **时间管理** - 不同班期有不同的开课时间
   - 学生只能选择开课中/即将开课的班期
   - 已结束的班期不再接收新选手

## 🗂️ 数据模型

### 1. 课程 (Course)
```javascript
{
  id: 'course_123',
  title: '前端开发基础',
  description: '...',
  creator: 'teacher_001',  // 创建者ID
  category: 'web',
  price: 99,
  coverImage: '/images/cover_123.jpg',
  status: 'published',  // draft | pending_review | published | archived
  createdAt: '2024-01-01',
  updatedAt: '2024-01-15',
  
  // 关键：班期列表
  termIds: ['term_001', 'term_002', 'term_003']
}
```

### 2. 班期 (Term)
```javascript
{
  id: 'term_001',
  courseId: 'course_123',
  name: '第一期（2024春季）',
  description: '春季班，从3月开始',
  
  // 时间管理
  startDate: '2024-03-01',
  endDate: '2024-05-31',
  enrollmentDeadline: '2024-02-25',  // 选课截止时间
  
  // 内容版本
  version: 1,  // 课程内容的版本号
  contentVersion: 1,  // 对应课程内容的版本
  
  // 班级列表
  classIds: ['class_001', 'class_002'],
  
  // 考试和作业（发布到班期）
  exams: [
    {
      id: 'exam_001',
      name: '章节测试',
      scheduledDate: '2024-03-15'
    }
  ],
  
  status: 'active',  // planning | active | completed | archived
  createdAt: '2024-02-01',
  createdBy: 'teacher_001'
}
```

### 3. 班级 (Class)
```javascript
{
  id: 'class_001',
  courseId: 'course_123',
```

### 4. 用户课程关系 (UserCourse)

## 🔄 业务流程

### 流程1：教师创建课程并开设班期

```
步骤1: 教师创建课程
  POST /api/courses
  {
    title: '前端开发基础',
    description: '...',
    category: 'web',
    price: 99
  }
  返回: Course { id: 'course_123', status: 'draft' }

步骤2: 教师编辑课程内容（章节、资源等）
  GET /api/courses/course_123
  PUT /api/courses/course_123/content

步骤3: 教师发布课程
  PUT /api/courses/course_123/publish
  返回: Course { status: 'pending_review' }
  
步骤4: 管理员审核
  GET /api/admin/course-audit
  PUT /api/admin/courses/course_123/approve
  返回: Course { status: 'published' }

步骤5: 教师为课程创建班期
  POST /api/courses/course_123/terms
  {
    name: '第一期（2024春季）',
    startDate: '2024-03-01',
    endDate: '2024-05-31',
    enrollmentDeadline: '2024-02-25'
  }
  返回: Term { id: 'term_001' }

步骤6: 教师在班期内创建班级
  POST /api/courses/course_123/terms/term_001/classes
  {
    name: '一班',
    capacity: 50
  }
  返回: Class { id: 'class_001' }
  
  如果满班：
  POST /api/courses/course_123/terms/term_001/classes
  {
    name: '二班',
    capacity: 50
  }
  返回: Class { id: 'class_002' }
```

### 流程2：学生选课加入班级

```
步骤1: 学生浏览课程
  GET /api/courses
  过滤: status = 'published'

步骤2: 学生查看课程详情和班期
  GET /api/courses/course_123
  返回: Course { ..., termIds: ['term_001', 'term_002'] }
  
  GET /api/courses/course_123/terms
  返回: [
    Term { id: 'term_001', status: 'active', classIds: ['class_001', 'class_002'] },
    Term { id: 'term_002', status: 'planning', ... }
  ]

步骤3: 学生选择班期（显示可用班级列表）
  GET /api/courses/course_123/terms/term_001/classes
  返回: [
    Class { id: 'class_001', name: '一班', capacity: 50, currentStudents: 45 },
    Class { id: 'class_002', name: '二班', capacity: 50, currentStudents: 38 }
  ]

步骤4: 学生选择班级并加入
  POST /api/courses/course_123/terms/term_001/classes/class_001/enroll
  返回: UserCourse { role: 'student', status: 'active' }
  
  错误处理：
  - 班级已满 → 建议加入其他班级
  - 选课截止 → 提示已无法选课
  - 已选过 → 提示已选课

步骤5: 学生进入课程学习
  GET /api/courses/course_123?termId=term_001&classId=class_001
```

### 流程3：学生参加考试并获得证书

```
步骤1: 查看班级内的考试
  GET /api/courses/course_123/terms/term_001/classes/class_001/exams

步骤2: 参加考试
  POST /api/exams/exam_001/answer
  { answers: [...] }

步骤3: 考试批改完成
  GET /api/exams/exam_001/result
  返回: ExamResult { score: 88, status: 'passed' }

步骤4: 系统自动检查是否通过
  if (score >= passingScore) {
    // 自动生成证书
    POST /api/certificates/generate
    {
      userId, courseId, termId, examId, score
    }
  }

步骤5: 学生查看证书
  GET /api/user/certificates
  返回: [
    Certificate { id: 'cert_12345', status: 'active', ... }
  ]

步骤6: 学生分享证书
  GET /api/certificate/cert_12345/share-link
  或扫描二维码：/certificate/share/cert_12345
```

### 流程4：教师向班级发布考试或作业

```
步骤1: 教师进入班期管理
  GET /api/teacher/courses/course_123/terms/term_001

步骤2: 查看班级列表
  GET /api/teacher/courses/course_123/terms/term_001/classes

步骤3: 为班级发布考试
  POST /api/teacher/courses/course_123/terms/term_001/exams
  {
    name: '章节测试',
    description: '...',
    questionsIds: ['q1', 'q2', ...],
    classIds: ['class_001', 'class_002'],  // 发布到所有班级
    startTime: '2024-03-15 10:00',
    endTime: '2024-03-15 11:00',
    passingScore: 60
  }

步骤4: 学生看到考试通知
  WebSocket / 轮询: 新考试发布到 classId
```

## 🛠️ API 端点设计

### 班期相关 API

```
GET /api/courses/:courseId/terms
  获取课程的所有班期
  返回: Term[]

POST /api/courses/:courseId/terms
  创建班期
  请求体: { name, startDate, endDate, enrollmentDeadline, version }
  返回: Term

GET /api/courses/:courseId/terms/:termId
  获取班期详情
  返回: Term

PUT /api/courses/:courseId/terms/:termId
  编辑班期
  返回: Term

DELETE /api/courses/:courseId/terms/:termId
  删除班期（仅限未开课的班期）
  返回: { success: true }
```

### 班级相关 API

```
GET /api/courses/:courseId/terms/:termId/classes
  获取班期内的所有班级
  返回: Class[]

POST /api/courses/:courseId/terms/:termId/classes
  创建班级
  请求体: { name, description, capacity }
  返回: Class

GET /api/courses/:courseId/terms/:termId/classes/:classId
  获取班级详情
  返回: Class

PUT /api/courses/:courseId/terms/:termId/classes/:classId
  编辑班级
  返回: Class

DELETE /api/courses/:courseId/terms/:termId/classes/:classId
  删除班级（仅限学生为0的班级）
  返回: { success: true }
```

### 班级学生管理 API

```
GET /api/courses/:courseId/terms/:termId/classes/:classId/students
  获取班级学生列表
  返回: User[]

POST /api/courses/:courseId/terms/:termId/classes/:classId/students
  添加学生到班级
  请求体: { userId }
  返回: Class (更新后)

POST /api/courses/:courseId/terms/:termId/classes/:classId/import-students
  批量导入学生
  请求体: { studentList: [{ userId, name, email }, ...] }
  返回: { success: true, imported: 10, failed: 2, errors: [...] }

DELETE /api/courses/:courseId/terms/:termId/classes/:classId/students/:studentId
  移除学生
  返回: Class (更新后)
```

### 选课相关 API

```
GET /api/courses/:courseId/available-terms
  获取可选的班期
  条件: status = 'active' 且 enrollmentDeadline > now
  返回: Term[]

POST /api/courses/:courseId/terms/:termId/classes/:classId/enroll
  学生选课（加入班级）
  返回: UserCourse
  错误: 班级已满、选课截止、已选课

POST /api/user/courses/:userCourseId/drop
  学生退课
  返回: { success: true }
```

### 电子证书 API

```
GET /api/user/certificates
  获取用户的所有证书
  返回: Certificate[]

GET /api/certificate/:certId
  获取证书详情
  返回: Certificate

GET /api/certificate/:certId/download
  下载证书 PDF
  返回: PDF 文件

GET /api/certificate/:certId/share-link
  生成证书分享链接
  返回: { shareLink: '/certificate/share/...' }

GET /api/certificate/share/:shareCode
  公开验证证书
  返回: Certificate (公开信息)

POST /api/certificates/generate
  [内部调用] 生成证书
  触发: 考试通过时自动调用
```

## 📊 数据库关系图

```
Courses (1) ──── (N) Terms
    │
    └── status: draft/pending_review/published/archived
    └── creator: user_id

Terms (1) ──── (N) Classes
    │
    └── courseId (foreign key)
    └── status: planning/active/completed/archived

Classes (1) ──── (N) UserCourse
    │
    └── termId (foreign key)
    └── capacity

UserCourse (N) ──── (1) Users
    └── courseId, termId, classId (foreign keys)
    └── role: student/teacher/creator

Exams (N) ──── (N) Classes (多对多)
    └── 一个考试可发布到多个班级

Certificates (N) ──── (1) UserCourse
    └── userId, courseId, termId, classId
    └── 基于用户参加的考试自动生成
```

## 🔐 权限控制

### 教师（课程创建者）权限
- ✓ 创建班期
- ✓ 编辑班期
- ✓ 创建班级
- ✓ 编辑班级
- ✓ 管理班级学生（添加/删除）
- ✓ 向班级发布考试和作业
- ✓ 查看班级的考试成绩
- ✗ 编辑他人的课程

### 学生权限
- ✓ 查看已发布的课程
- ✓ 选择班期和班级选课
- ✓ 参加班级的考试和作业
- ✓ 查看自己的成绩和证书
- ✗ 创建班期或班级
- ✗ 查看其他学生的成绩

### 管理员权限
- ✓ 审核课程发布申请
- ✓ 查看所有课程、班期、班级
- ✓ 吊销证书（特殊情况）
- ✓ 用户管理
- ✗ 创建班期或班级（权限在教师）

## 💡 实现建议

### 前端 Store 结构

```javascript
// store/modules/termClass.js
export default {
  state: {
    terms: [],
    classes: {},  // { termId: [classes] }
    userCourses: [],  // 用户选过的课程
    certificates: []
  },
  
  mutations: {
    SET_TERMS(state, terms) { state.terms = terms },
    ADD_TERM(state, term) { state.terms.push(term) },
    SET_CLASSES(state, { termId, classes }) {
      state.classes[termId] = classes
    }
  },
  
  actions: {
    fetchTerms({ commit }, courseId) {
      return api.get(`/courses/${courseId}/terms`)
        .then(terms => {
          commit('SET_TERMS', terms)
          return terms
        })
    },
    
    fetchClasses({ commit }, { courseId, termId }) {
      return api.get(`/courses/${courseId}/terms/${termId}/classes`)
        .then(classes => {
          commit('SET_CLASSES', { termId, classes })
          return classes
        })
    },
    
    enrollClass({ commit }, { courseId, termId, classId }) {
      return api.post(
        `/courses/${courseId}/terms/${termId}/classes/${classId}/enroll`
      ).then(userCourse => {
        commit('ADD_USER_COURSE', userCourse)
        return userCourse
      })
    }
  }
}
```

### 关键的 Vue 组件交互流程

```
CourseDetail.vue
  ↓
显示"选课"按钮
  ↓
点击 → 显示班期选择对话框
  ↓
  TermSelector.vue
    ├─ 获取 /courses/:courseId/terms
    ├─ 过滤 status = 'active'
    ├─ 用户选择班期
    └─ 回调 onTermSelected(term)
      ↓
      显示班级选择对话框
      ↓
      ClassSelector.vue
        ├─ 获取 /courses/:courseId/terms/:termId/classes
        ├─ 显示班级列表（包含容量信息）
        ├─ 用户选择班级
        └─ 回调 onClassSelected(class)
          ↓
          POST /courses/:courseId/terms/:termId/classes/:classId/enroll
          ↓
          选课成功，进入课程
```

这个设计完全支持你的业务模式，充分体现了课程迭代、学生分组、批量操作、证书颁发等关键需求。🎉
