# 电子证书系统设计文档

## 📜 系统概述

### 设计背景

在你的在线教育平台中，电子证书是：
1. **学习成果的凭证** - 证明学生学过某门课
2. **结业考核的证明** - 通过考试获得的荣誉证书
3. **可分享的成就** - 可以分享到社交媒体或简历
4. **重要的营销工具** - 增强平台口碑

### 核心设计原则

- **自动颁发** - 考试通过后自动生成，无需教师操作
- **一次一证** - 每个用户对每门课程只有一张证书
- **永久有效** - 默认证书永不过期（除非被吊销）
- **可验证** - 提供证书验证链接，防止伪造
- **易分享** - 支持下载、截图、链接分享

## 🔄 业务流程

### 流程1：自动颁发证书

```
学生参加考试
  ↓
POST /api/exams/:examId/submit
  ├─ 答卷保存
  ├─ 自动批改（客观题）
  ├─ 计算总分
  └─ 返回 score
  ↓
检查是否通过
  if (score >= passingScore) {
    ↓
    自动生成证书
    POST /api/certificates/auto-generate (后端内部调用)
    {
      userId, userName, courseId, courseName,
      termId, termName, examId, examName,
      score, passingScore, issueDate
    }
    ↓
    返回证书ID给前端
    ↓
    发送通知给用户
    "恭喜！您已通过考试，电子证书已颁发"
  }
```

### 流程2：学生查看证书

```
用户进入"我的证书"页面
  ↓
GET /api/user/certificates
  返回: Certificate[]
  ↓
显示证书列表
  ├─ 证书封面/预览
  ├─ 课程名称
  ├─ 成绩信息
  ├─ 颁发日期
  └─ 操作按钮（查看、下载、分享）
  ↓
用户点击"查看详情"
  ↓
GET /api/certificate/:certId
  返回完整证书信息
  ↓
渲染证书详情页
```

### 流程3：证书下载

```
用户点击"下载证书"按钮
  ↓
前端发起下载请求
GET /api/certificate/:certId/download
  ↓
后端生成PDF
  ├─ 读取证书模板
  ├─ 填充用户数据
  ├─ 生成PDF文件
  └─ 临时存储或直接返回
  ↓
浏览器下载文件
  文件名: 证书_张三_前端开发基础_2024.pdf
```

### 流程4：证书分享

```
用户点击"分享"按钮
  ↓
弹出分享选项
  ├─ 复制分享链接
  ├─ 生成分享二维码
  ├─ 分享到社交媒体
  └─ 下载证书
  ↓
如果选择"分享链接"
  POST /api/certificate/:certId/generate-share-link
  返回: { shareLink: 'https://platform.com/certificate/share/abc123' }
  ↓
分享链接可能需要设置：
  - 密码保护（可选）
  - 有效期（可选）
  - 访问次数限制（可选）
  ↓
接收人通过链接访问
GET /api/certificate/share/abc123
  ↓
显示证书公开信息（无需登录）
  ├─ 学生名称
  ├─ 课程名称
  ├─ 成绩
  ├─ 颁发日期
  └─ "验证证书"链接
```

### 流程5：证书验证

```
任何人可以访问公开证书链接
  ↓
GET /api/certificate/share/:shareCode
  ├─ 验证 shareCode 有效性
  ├─ 验证证书状态（active/revoked/expired）
  ├─ 记录浏览统计
  └─ 返回证书信息
  ↓
显示验证结果
  ├─ 证书有效：✓ 证书有效
  ├─ 证书无效：✗ 证书已被吊销/过期
  └─ 证书不存在：✗ 证书不存在
```

### 流程6：证书吊销（管理员）

```
管理员发现学生考试作弊
  ↓
进入管理员后台 → 证书管理
  ↓
搜索证书
  ↓
点击"吊销证书"按钮
  ↓
弹出吊销对话框
  - 输入吊销原因（必填）
  - 确认吊销
  ↓
PUT /api/admin/certificates/:certId/revoke
  {
    revokeReason: '考试作弊'
  }
  ↓
证书状态变更为 'revoked'
  ↓
发送通知给学生
  ↓
分享链接显示：✗ 该证书已被吊销
```

## 🛠️ API 设计

### 证书查询 API

```
GET /api/user/certificates
  获取当前用户的所有证书
  查询参数:
    - page=1&limit=10 (分页)
    - status=active (状态筛选)
    - courseId=xxx (课程筛选)
  返回: {
    list: Certificate[],
    total: 100,
    page: 1,
    limit: 10
  }

GET /api/certificate/:certId
  获取证书详情
  返回: Certificate

GET /api/user/certificates/stats
  获取证书统计
  返回: {
    totalCertificates: 5,
    activeCertificates: 5,
    revokedCertificates: 0,
    expiredCertificates: 0
  }
```

### 证书颁发 API

```
POST /api/certificates/auto-generate [内部调用]
  自动生成证书（考试通过时调用）
  请求体: {
    userId,
    userName,
    courseId,
    courseName,
    termId,
    termName,
    examId,
    examName,
    score,
    passingScore
  }
  返回: Certificate

POST /api/certificates/manual-generate [管理员]
  手动颁发证书
  请求体: {
    userId,
    courseId,
    reason: '特殊情况下颁发'
  }
  返回: Certificate
```

### 证书下载 API

```
GET /api/certificate/:certId/download
  下载证书 PDF
  返回: PDF 二进制文件
  Content-Disposition: attachment; filename="证书_张三.pdf"

POST /api/certificate/:certId/preview
  预览证书（不下载）
  返回: { url: 'blob:...' } 或 Base64 数据
```

### 证书分享 API

```
POST /api/certificate/:certId/generate-share-link
  生成分享链接
  请求体 (可选): {
    password: '123456',     // 可选分享密码
    expiryDays: 30,         // 可选有效期（天）
    maxViews: 100           // 可选最大浏览次数
  }
  返回: {
    shareLink: 'https://platform.com/certificate/share/abc123',
    shareCode: 'abc123',
    qrCode: 'data:image/png;base64,...'
  }

GET /api/certificate/share/:shareCode
  获取公开证书信息
  返回: {
    id: '...',
    userName: '张三',
    courseName: '前端开发基础',
    score: 88,
    issueDate: '2024-04-15',
    status: 'active'
  }

PUT /api/certificate/:certId/share-link/expire
  立即过期分享链接
  返回: { success: true }
```

### 证书管理 API (管理员)

```
GET /api/admin/certificates
  获取所有证书列表（分页、筛选）
  查询参数:
    - page, limit
    - userId, courseId, status
  返回: { list, total, page, limit }

PUT /api/admin/certificates/:certId/revoke
  吊销证书
  请求体: {
    revokeReason: '考试作弊'
  }
  返回: Certificate { status: 'revoked', revokedAt, revokeReason }

DELETE /api/admin/certificates/:certId
  删除证书（仅限未分享的证书）
  返回: { success: true }

GET /api/admin/certificates/stats
  证书统计信息
  返回: {
    totalCertificates: 1000,
    activeCertificates: 950,
    revokedCertificates: 30,
    expiredCertificates: 20,
    certificatesByMonth: { ... }
  }
```

## 🎨 前端组件设计

### 1. MyCertificates.vue - 我的证书页面

```vue
<template>
  <div class="my-certificates">
    <h1>我的证书</h1>
    
    <!-- 证书统计 -->
    <el-row :gutter="20">
      <el-col :xs="24" :sm="6">
        <StatCard title="总证书数" :value="stats.total" icon="certificate" />
      </el-col>
    </el-row>
    
    <!-- 筛选 -->
    <el-row :gutter="20" class="filters">
      <el-col :xs="24" :sm="8">
        <el-select v-model="filterCourse" placeholder="选择课程">
          <el-option label="全部课程" value="" />
          <el-option v-for="course in courses" :key="course.id" 
                     :label="course.name" :value="course.id" />
        </el-select>
      </el-col>
      <el-col :xs="24" :sm="8">
        <el-input v-model="searchKey" placeholder="搜索证书编号或课程名" />
      </el-col>
      <el-col :xs="24" :sm="8">
        <el-button type="primary" @click="search">搜索</el-button>
      </el-col>
    </el-row>
    
    <!-- 证书列表 -->
    <el-table :data="certificates" v-loading="loading" class="certificate-table">
      <el-table-column prop="courseName" label="课程名称" width="200" />
      <el-table-column prop="termName" label="班期" width="150" />
      <el-table-column prop="score" label="成绩" width="80">
        <template slot-scope="scope">
          {{ scope.row.score }} / {{ scope.row.passingScore }}
        </template>
      </el-table-column>
      <el-table-column prop="issueDate" label="颁发日期" width="120" />
      <el-table-column prop="status" label="状态" width="80">
        <template slot-scope="scope">
          <el-tag :type="getStatusType(scope.row.status)">
            {{ getStatusText(scope.row.status) }}
          </el-tag>
        </template>
      </el-table-column>
      <el-table-column label="操作" width="200" fixed="right">
        <template slot-scope="scope">
          <el-button size="small" type="text" @click="viewDetail(scope.row)">
            查看
          </el-button>
          <el-button size="small" type="text" @click="downloadCert(scope.row)">
            下载
          </el-button>
          <el-button size="small" type="text" @click="shareCert(scope.row)">
            分享
          </el-button>
        </template>
      </el-table-column>
    </el-table>
    
    <!-- 分页 -->
    <el-pagination
      :current-page="page"
      :page-size="pageSize"
      :total="total"
      @current-change="onPageChange"
    />
    
    <!-- 详情对话框 -->
    <CertificateDetail :visible.sync="detailVisible" :cert="selectedCert" />
    
    <!-- 分享对话框 -->
    <CertificateShare :visible.sync="shareVisible" :cert="selectedCert" />
  </div>
</template>

<script>
export default {
  name: 'MyCertificates',
  components: {
    CertificateDetail,
    CertificateShare
  },
  data() {
    return {
      certificates: [],
      loading: false,
      page: 1,
      pageSize: 10,
      total: 0,
      filterCourse: '',
      searchKey: '',
      stats: { total: 0 },
      courses: [],
      detailVisible: false,
      shareVisible: false,
      selectedCert: null
    }
  },
  created() {
    this.fetchCertificates()
    this.fetchStats()
    this.fetchCourses()
  },
  methods: {
    fetchCertificates() {
      this.loading = true
      this.$api.get('/user/certificates', {
        params: {
          page: this.page,
          limit: this.pageSize,
          courseId: this.filterCourse,
          search: this.searchKey
        }
      })
        .then(res => {
          this.certificates = res.list
          this.total = res.total
        })
        .catch(err => this.$message.error('加载证书失败'))
        .finally(() => { this.loading = false })
    },
    
    fetchStats() {
      this.$api.get('/user/certificates/stats')
        .then(res => { this.stats = res })
    },
    
    fetchCourses() {
      this.$api.get('/courses')
        .then(res => { this.courses = res })
    },
    
    viewDetail(cert) {
      this.selectedCert = cert
      this.detailVisible = true
    },
    
    downloadCert(cert) {
      window.location.href = `/api/certificate/${cert.id}/download`
    },
    
    shareCert(cert) {
      this.selectedCert = cert
      this.shareVisible = true
    },
    
    search() {
      this.page = 1
      this.fetchCertificates()
    },
    
    onPageChange(page) {
      this.page = page
      this.fetchCertificates()
    },
    
    getStatusType(status) {
      const types = {
        active: 'success',
        revoked: 'danger',
        expired: 'warning'
      }
      return types[status] || 'info'
    },
    
    getStatusText(status) {
      const texts = {
        active: '有效',
        revoked: '已吊销',
        expired: '已过期'
      }
      return texts[status] || status
    }
  }
}
</script>
```

  watch: {
    visible(val) {
      if (val && this.cert) {
        this.generateShareLink()
      }
    }
  },
  methods: {
    generateShareLink() {
      this.$api.post(`/certificate/${this.cert.id}/generate-share-link`, {
        password: this.enablePassword ? this.password : undefined,
        expiryDays: this.enableExpiry ? this.calculateDays() : undefined
      })
        .then(res => {
          this.shareLink = res.shareLink
          this.qrCode = res.qrCode
        })
        .catch(() => this.$message.error('生成分享链接失败'))
    },
    
    copyLink() {
      navigator.clipboard.writeText(this.shareLink)
      this.$message.success('链接已复制到剪贴板')
    },
    
    shareToClipboard() {
      this.copyLink()
    },
    
    shareToWeChat() {
      // WeChat 分享（需要调用 WeChat SDK）
      this.$message.info('请使用微信分享功能')
    },
    
    shareToQQ() {
      // QQ 分享
      this.$message.info('请使用 QQ 分享功能')
    },
    
    downloadQRCode() {
      const link = document.createElement('a')
      link.href = this.qrCode
      link.download = `证书分享码_${this.cert.courseName}.png`
      link.click()
    },
    
    calculateDays() {
      return Math.ceil((this.expiryDate - new Date()) / (1000 * 60 * 60 * 24))
    }
  }
}
</script>

## 🔒 安全考虑

### 1. 防伪措施
- 证书编号唯一且不可预测
- 证书包含用户信息、课程信息、成绩等多项验证字段
- 分享链接包含加密的 shareCode
- 可选的分享密码保护

### 2. 隐私保护
- 公开证书仅显示必要信息（姓名、课程、成绩、日期）
- 不显示用户邮箱、电话等个人隐私
- 分享链接可设置过期时间
- 可以随时取消分享

### 3. 审计日志
- 记录所有证书颁发
- 记录所有证书吊销及原因
- 记录证书被查看和分享的次数
- 便于审计和追踪
